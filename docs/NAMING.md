# Name and tagline

**Ibert-Iam** is read as **“Ibert — I am.”** It is a personal name, not an acronym.

It is **not** IAM (Identity and Access Management). Threat Atlas works with IT security and open-source
threat intelligence; the name does not describe an identity or access-management product or service.

The old handle `ibert-ai` was renamed to `Ibert-Iam`. The old name is kept as an empty GitHub organisation
only so old links redirect; it is not a product name and must not be used for new repositories or content.

## Taglines

Short, playful:

> **Ibert-Iam — Ibert, I am. Not IAM.**

Expanded:

> Ibert-Iam means “Ibert — I am”. It is not IAM (Identity and Access Management). We work with IT security, and
> the name is personal, not an acronym.

Swedish:

> **Ibert-Iam — Ibert, jag är. Inte IAM.**
>
> Ibert-Iam betyder ”Ibert – jag är”. Det är inte IAM (Identity and Access Management). Vi arbetar med
> IT-säkerhet, och namnet är personligt, inte en förkortning.

## Where to use it

- README, site “About the name”, release notes and the first post after a rename.
- Social bios where the name could be confused with IAM.
- Not in the logo itself; keep the logo as **Threat Atlas Project — Open Source**.
- Do not expand it to “Identity and Access Management” anywhere, even as a joke, because search and AI systems
  may treat that as a definition.

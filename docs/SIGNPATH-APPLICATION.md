# SignPath Foundation application draft

Publish the GitHub repository and an unsigned release first. Do not substitute
an inaccessible/local URL or claim signing approval before it is granted.

- Project name: Threat Atlas SOC
- Repository and homepage: the actual public GitHub repository URL
- Download: that repository's /releases page, after a release exists
- Privacy: the repository's /blob/main/PRIVACY.md URL
- Category: Other
- Maintainer: Individual maintainer(s) for a personal project, or company if company-maintained
- Build system: GitHub Actions once a successful run exists
- Discovery: ChatGPT
- Company: optional; leave blank for a personal application
- Wikipedia: leave blank

Tagline:
A native screensaver that visualizes live internet threat telemetry on Windows and macOS.

Description:
Threat Atlas SOC is an open-source screensaver that presents public internet threat
telemetry as an animated world map, activity counters, and recent observations. It
runs natively on Windows and macOS and clearly indicates when its data feed is live,
stale, or offline.

Reputation (update with evidence after publishing):
This is a new project preparing its first public GitHub release. It has been tested
by its maintainer on Windows and macOS. It does not yet have public download
statistics, independent reviews, or an established user community.

Enter the maintainer's real name and chosen account email. Review all terms and
privacy consent personally. Approval is at SignPath's discretion, especially for
a newly published project. The free signing certificate identifies SignPath
Foundation as publisher. Its role/review/build-provenance requirements must be
followed; see https://signpath.org/terms.

After acceptance, configure the actual SignPath organization/project/policies,
protect signing credentials and approval roles, sign the SCR before packaging,
and sign the resulting MSI. Add the required signing credit and actual team roles
to the download page once accurate. Do not publish a false 'signed by SignPath'
claim while the application is pending.

Tagline:
A native screensaver that visualizes live internet threat telemetry on Windows and macOS.

Description:
Threat Atlas SOC is an open-source screensaver that presents public internet threat
telemetry as an animated world map, activity counters, and recent observations. It
runs natively on Windows and macOS and clearly indicates when its data feed is live,
stale, or offline.

Threat Atlas SOC - Windows installation

The 0.4.2-rc.1 MSI download is withdrawn; the standalone Windows ZIP remains available for manual evaluation. These steps describe the corrected all-users installer used by the 0.4.6-beta.1 Windows candidate. Download only the package matching the release version you intend to install.

1. Double-click the MSI and approve the administrator prompt. It installs one 64-bit ThreatAtlas.scr into System32 and these documents into Program Files\Threat Atlas.
2. Open Start > Threat Atlas SOC > Set up Threat Atlas.
3. In Screen Saver Settings, choose ThreatAtlas if needed, set the wait time, and Apply.
4. Use Preview Threat Atlas for a normal live window.

The MSI needs an administrator account but no manual file copying. If an older per-user Threat Atlas SOC is installed, uninstall it first; the installer stops and tells you. If the saver is missing from Screen Saver Settings, see the troubleshooting guide; successful file installation alone does not prove interactive discovery. The MSI does not
change your password, sign-in requirement, idle timeout or active screensaver.
An unsigned build may show a Windows security warning. Public distribution
should use a trusted code-signing identity for both the SCR and MSI.

Uninstall: first select a different screen saver, then uninstall Threat Atlas SOC
from Windows Settings > Apps. Do not delete the installed SCR manually.
Windows 10/11 x64. Internet access to GreyNoise's public feed is required.
This is a visual telemetry viewer, not an endpoint security product.

Downloaded SCR/ZIP: after checking the official source/checksum and choosing to trust that particular file, inspect File Explorer > Properties > General > Unblock (if present). A temporary extraction folder such as C:\Temp does not prove the marker is gone. Do not disable Windows protections or broadly unblock Downloads.

On 64-bit Windows, System32 is the 64-bit directory and SysWOW64 is 32-bit. This package is x64 and installs only to System32; do not copy it to SysWOW64. Manually copied files are not owned or cleaned up by this MSI.

Detailed Windows installation/troubleshooting:
https://github.com/ibert-ai/threat-atlas/blob/main/docs/WINDOWS-INSTALLATION.md

Manual System32 copying requires elevation: open the copying tool or terminal with Run as administrator. The MSI requests administrator approval itself. Do not run the screensaver routinely as administrator. Automatic updates are not included in the all-users MSI; install future verified packages manually.
